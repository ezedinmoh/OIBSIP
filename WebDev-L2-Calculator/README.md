# Modern Calculator

A responsive, modern calculator built with HTML, CSS, and vanilla JavaScript as part of the Oasis Infobyte AICTE OIB-SIP Web Development Internship.

## ✨ Features

- Basic arithmetic operations
- Addition, subtraction, multiplication, and division
- Decimal calculations
- Operator chaining
- Clear and backspace controls
- Division-by-zero handling
- Floating-point precision handling
- Number formatting with comma separators
- Maximum digit protection
- Large-number display handling
- Keyboard support
- Responsive design
- Modern user interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- CSS Grid

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

Navigate to the project directory and open `index.html` in a modern web browser.

No package installation or build process is required.

## 💻 Usage

Use the on-screen calculator buttons or your keyboard to perform calculations.

### Keyboard Controls

| Key | Action |
|---|---|
| `0–9` | Enter numbers |
| `.` | Decimal point |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `Enter` / `=` | Calculate |
| `Backspace` | Delete the last digit |
| `Escape` | Clear calculator |
