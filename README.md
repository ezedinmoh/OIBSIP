## 🗂️ Task Index

### Task 1 · Calculator

**Folder:** `WebDev-L2-Calculator/`

A fully functional browser-based calculator capable of performing basic arithmetic operations with a user-friendly button interface. Built with HTML5, CSS3, and Vanilla JavaScript.

**Tech Stack:** HTML5, CSS3, JavaScript (Vanilla)

**Key Features:**
- Basic arithmetic: addition, subtraction, multiplication, division
- Decimal point support
- Operator chaining
- Clear and backspace functionality
- Division-by-zero error handling
- Floating-point precision handling
- Keyboard support
- CSS Grid button layout
- Responsive design

🔗 [View Project](./WebDev-L2-Calculator/)

### Task 2 · Tribute Page

**Folder:** `WebDev-L2-TributePage/`

An editorial-style tribute page dedicated to Emperor Tewodros II of Ethiopia (1855–1868), exploring his vision of a unified Ethiopia, his military campaigns, and his legacy. Built with HTML5 and CSS3.

**Tech Stack:** HTML5, CSS3, JavaScript (optional enhancements)

**Key Features:**
- Historical hero section with prominent image
- Original biography and tribute content
- Interactive timeline of key achievements
- Styled quote block
- Multiple background colours across sections
- Serif and sans-serif font pairing
- Scroll-reveal animations
- Responsive desktop and mobile layout

🔗 [View Project](./WebDev-L2-TributePage/)

### Task 3 · To-Do Web App

**Folder:** `WebDev-L2-ToDo/`

An interactive personal task manager that allows users to add, edit, complete, and delete tasks. Tasks are organized into separate Pending and Completed lists and persist across page refreshes using `localStorage`.

**Tech Stack:** HTML5, CSS3, JavaScript (Vanilla)

**Key Features:**
- Add, edit, and delete tasks
- Mark tasks as complete — moves to Completed list
- Move completed tasks back to pending
- Task count indicators for pending and completed
- Timestamps on creation and completion
- localStorage persistence across page refreshes
- Empty state messages
- Responsive design

🔗 [View Project](./WebDev-L2-ToDo/)

---

### Task 4 · Login Authentication System

**Folder:** `WebDev-L2-Login-Authentication/`

A full-stack login authentication system with user registration, login validation, session management, and a protected dashboard. Passwords are hashed with bcrypt and never stored in plain text.

**Tech Stack:** Node.js, Express.js, SQLite (better-sqlite3), bcryptjs, express-session, HTML5, CSS3, JavaScript (Vanilla)

**Key Features:**
- User registration with email and password
- Duplicate email detection
- Password hashing with bcrypt (12 salt rounds)
- Session-based authentication with HTTP-only cookies
- Protected dashboard — redirects to login if no session
- Logout clears session and cookie
- Client-side and server-side form validation
- Generic error messages for invalid credentials

🔗 [View Project](./WebDev-L2-Login-Authentication/)
